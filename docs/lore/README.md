## 1. 版权红线（不可协商）

1. 词条**只记设定要点，用自己的话写**，每条不超过 80 字。
2. **严禁摘抄原著语句、对白、描写**。检索工具返回的原文片段只用于判断事实，不得进入任何产出文件。
3. 引用一律只写**章号**，不写原句。
4. 原著文本放在 `H:/Work/Kys/novel`，**不入库**、不复制、不转换格式分发。
5. 游戏内全部对白为原创改编，不得逐句转写原著。

违反以上任何一条的产出，一律打回重写。

## 3. 词条字段

每个词条必须包含下列字段。Markdown 表格或分节皆可，字段名固定。

| 字段 | 必填 | 取值 | 说明 |
| --- | --- | --- | --- |
| `id` | 是 | 拼音/英文下划线 | 与 `data/` 中的 id 一致，全局唯一 |
| `name` | 是 | 中文 | 游戏内显示名 |
| `origin` | 是 | `原著` / `改编` / `原著名改编设定` | 见第 4 节判定规则 |
| `source_ch` | 原著条目必填 | 章号或范围 | 原著出处；改编条目填 `—` |
| `first_chapter` | 是 | 1–14 | 在**游戏**中首次出现的章，对应 `docs/大纲.md` v3.1 的 14 章切分 |
| `summary` | 是 | ≤80 字自述 | 设定要点 |
| `game_use` | 是 | ≤60 字 | 在游戏中如何呈现（玩法/剧情作用） |
| `numeric_claim` | 是 | `true` / `false` | 条目是否含数字断言 |
| `verified` | 是 | `true` / `false` | 是否已对照原文确证 |
| `faction` | 人物/地点必填 | 势力 id | 对应 `势力与地理.md` |
| `relations` | 人物选填 | id 列表 | 与其他人物的关系 |

## 4. `origin` 判定规则

| 取值 | 判定 | 处理 |
| --- | --- | --- |
| `原著` | 名称与核心设定均出自原著，已查到章号 | 直接使用 |
| `原著名改编设定` | 名称出自原著，但游戏为玩法需要改了设定 | 必须在 `game_use` 写明改了什么 |
| `改编` | 原著查无此名，为游戏原创 | **必须改名**，不得使用与原著相近的名字冒充 |

**P0 截止日仍无法在原文中找到出处的条目，一律降级为 `改编` 并改名**，不得长期悬置。
悬置的条目会阻塞脚本生产，这是 P0 的硬规则。

## 5. 数字型设定（`numeric_claim`）

凡条目中含有数字断言——周期、年限、境界层数、数量、人数、年龄、时间跨度、门派数目——
一律置 `numeric_claim: true`，并**单独在 `数字设定.md` 中登记**，附章号。

理由：数字是最容易记错的一类设定。原方案里"三百年一开""每三十年""三战皆败""七大派""魔道六宗"
全部未经校对即写入，这类断言必须逐条查证。

`数字设定.md` 字段：`设定` | `数值` | `出处章` | `verified` | `影响范围`（哪些脚本/数据依赖它）。

## 7. 变更治理

1. 词条变更必须附**影响脚本列表**：列出引用该词条的 `scripts/`、`data/`、`maps/` 文件。
2. 变更由校对代理回灌到已写脚本，不得只改词条不改引用。
3. `tools/validate.py` 校验：`data/` 中出现的 id 必须在词条库登记；词条库中 `verified: false`
   的条目不得被主线脚本引用。
4. 校对代理独立于编剧代理与关卡代理，不得自审自批。

## 8. 检索工具

```bash
cd /h/Work/Kys/tools/novel && export PYTHONIOENCODING=utf-8
python novel.py find "关键词" --limit 8 --window 60 --from 1 --to 363
python novel.py read 42 --start 0 --lines 40
python novel.py toc --vol 1
python novel.py where 42
```

注意：

- **每条命令必须带 `PYTHONIOENCODING=utf-8`**。终端代码页是 GBK，不设此变量中文输出会乱码；
  "肉眼看终端中文"是不可信判据。
- `find` 的 `--window` 硬上限 200 字，`read` 单次硬上限 120 行——工具层面限制摘抄规模。
- 原文为 GB18030 编码，索引在 `tools/novel/chapters.json`（2451 章 / 12 卷）。
