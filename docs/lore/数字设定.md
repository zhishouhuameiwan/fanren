## 矛盾/存疑清单（数字相关，逐条列出，不作调和）

1. **血色禁地/血色试炼的开放与圈封周期，已复核为同一机制的三个层次，数字不矛盾**：
   - 常规衰弱窗口（ch160）：每五年出现五天的禁制衰弱期，结丹修士可合力破禁，七派据此安排试炼。
   - 临时圈封周期（ch172）：每三四百年一次，用于缓解频繁开启造成的灵气流失。
   本次圈封安排（ch172）：五年后的下一届试炼结束后起封六十年；下一届仍会开启，且是封闭前最后一届。

2. **大衍诀的 `numeric_claim` 标记不一致**：`人间篇-校对.md`「四、功法法术」表中将大衍诀标为 `numeric_claim: 否`（ch232、240 首次出现时确无数字），但 `乱星海篇-校对.md`「六、数字型设定清单」给出了具体数字（第2层耗6年、可分神100余份；第3层耗20余年，ch374、398）。二者并不矛盾（数字是后续章节才揭示的），但反映出**同一设定条目在跨篇校对中的 `numeric_claim` 分类可能不同步**，登记 `数字设定.md` 时需注意此类"前期无数字、后期补数字"的条目。

3. **银月（狼形器灵）首见章不一致**：`势力与地理.md` 标注 ch615；`乱星海篇-校对.md` 标注 ch483（虚天殿内被收服）。两份文件均属"三份校对"范围内，互相冲突，未做调和，需人工核对原文。

4. **韩立年龄推算风险**：`乱星海篇-校对.md` 给出 ch639/640"结婴时堪堪二百岁"，与 ch596"离乡百余年"两个锚点，均不属于本篇（14章覆盖至ch596）时间范围内的确切年龄；两份校对文件都已明确提示"不得推算"，本表遵照执行，仅摘录已确证的四个人间篇年龄锚点（10/14/16/18-19岁）。
