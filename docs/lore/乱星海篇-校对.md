## 四、地点与势力

### 4.1 地理划分（ch389，全篇最高杠杆条目）
- 乱星海极大，实际边界无人知晓；至今的海域图只是真正海域的一小部分。
- 已探明海域称**内星海**，一般人口中的「乱星海」即指内星海。
- 未探明的外围海域称**外星海**，别名**妖海**；传说其中妖兽可与元婴期修士抗衡。
- 上古时内外星海皆为妖兽所据，后由历代先辈铲除强妖，才开拓出今日的内星海。
- 韩立落点在**内星海西南角**；附近三大岛为**尾星岛、魁星岛、桑星岛**（ch365）。

### 4.2 星宫（＝天星宫）——统治势力定名
- **正式名称：「星宫」**，行文中亦作「天星宫」。是管辖整个内星海的官方势力，存在年月久到典籍亦无确数，创立缘由众说纷纭（一说是上古铲妖先辈所建，一说是某代巨枭统一后所立）。
- 首脑为两位城主，号**天星双圣**，从不出天星城、从不公开露面；名号已流传近千年，外界猜测其为元婴后期或化神。
- 直辖分岛：内星海**外围八区域**各取三大岛＝**外二十四星岛**；**中部四区域**各取三大岛＝**内十二星岛**，对天星城成拱卫之势。
- **内十二星岛**岛主由两位圣主各选六人任命；**外二十四星岛**岛主每**百年**在天星城公开挑战选拔，该盛会称**摘星大会**。
- 魁星岛即外二十四星岛之一。
- ch500 起，正道万法门总护法**万三谷**与魔道第一人**六道极圣**联手成立**逆星盟**，以打破星宫霸权为纲领，先攻外星岛，再图内星岛，乱星海全面内战。

### 4.3 天星城
- 建在内星海中部一座巨岛上的超级城市，核心是一座天生灵脉之山（圣山）。
- 圣山自下而上每盘旋一圈为一层，共 **81 层**：前 **50 层**对外开放租住宅／洞府（越高越贵、灵气越足），后 **30 层**仅星宫之人可居，**最高一层为圣宫**，双圣主居所。
- 城内不准斗法；长住者按月缴灵石（持红色指环为凭）。除此之外星宫不干涉城中事务，连自己通缉的魔头只要不生事也不主动缉拿——故此城自由而龙蛇混杂。
- 商业：各大商家常年设门面；**丰乐拍卖行**号称天星城第一拍卖行；**白门阁**为书铺，售乱星海全部已知妖兽资料。
- **星空殿**位于第 50 层，内设成排传送阵，通往外星海数十座「妖兽岛」。收费**按次不按人：一次 700 灵石，最多送七人**。
- 韩立在此租下**第三十九层洞府**（ch391、397），并在坊市开**青竹小轩**（ch412-413）。

### 4.4 妖丹经济（原著无「猎妖令」）
- 制度实体是**传送阵付费 → 自由猎杀 → 回城卖丹**，没有任何许可证或令牌。「猎妖」「猎妖令」「星宫令」「妖丹令」在全书**均为 0 命中**。
- 猎法：把**霓裳草／诱妖草**种在困妖法阵中作饵，妖兽自来，杀之取内丹与材料（ch396、523、527）。风险是可能把六七级妖兽也引来。
- 售法：天星城／黑石城的商行（如**明珠轩**）设鉴宝厅直接收购，或设竞宝厅拍卖（ch513）。另有**结丹修士专属的「交换会」**以物易物（ch535-537）。
- 妖兽等阶：1-10 级；**五级妖兽 ≈ 结丹初期**（ch503）；五级是常规目标，六七级有死亡风险，八级以上只有元婴才敢碰（ch395）。
- **七级→八级需渡「化形雷劫」**；**八级＝化形初阶，九级＝化形第二阶**（ch520、542、544）；十级只是传闻（ch516）。
- 价值锚点：**五级妖丹约值近千灵石；六级妖丹足够一名筑基修士一生修炼无忧**（ch389）。韩立外星海一趟收得数百颗五级妖丹，自估最少值数十万灵石（ch397）。七级妖丹在拍卖行是天价，由元婴买走（ch513）。
- 乱星海丹道与天南根本不同：**以海中妖兽（妖丹）入药**（ch377）；五级妖丹可替代稀有灵草入筑基丹方。

### 4.5 其他势力
夜龙岛、四大商盟、魅魔宗、三仙门（三仙宗）、极阴岛、六连殿、登仙阁（魁星岛的定居／灵地登记机构）、妙音门、青阳门、碧云门、青灵门、逆星盟、六道、万法门；外星海则有黑石城的多家元婴背景商行、以及蛟龙／狻猊等海族妖修。

### 4.6 韩立在乱星海的落脚点序列（地图设计直接依据）
1. **无名孤岛**（ch364）：古传送阵所在的石室＋青石阶梯＋海边峭壁，原著未给名。停留极短。
2. **魁星岛**（ch367-371）：青云山有三大巨峰＋**367 座小山峰**；灵气最浓的 **36 座**每**十年**一次公开挑战易主；筑基期修士可自动获得一座普通山峰。**登仙阁**办定居与灵地手续。坊市名**天都街**。
3. **小寰岛**（ch372-388）：韩立选定的修炼之地。岛长**六七十里**，有数里长小灵脉，设小型防护阵与一座数百人的小镇，阵法灵石几乎全由韩立自付。真假两座洞府＋三座法阵，地道相连。**这里才是「荒岛洞府＋灵田」的原型。**
4. **海猿岛**（ch385-386）：首次冲丹之地（失败）。
5. **天星城**（ch390 起）：三十九层洞府、青竹小轩、闭关结丹。
6. **凝翠岛等外星海妖兽岛**（ch393-397）：诱妖、猎妖取丹。
7. **虚天殿**（ch431-499）：三百年一现的空中玉殿，外殿→鬼冤之地→冰火道→宝光阁→内殿五层。
8. **奇渊岛 / 黑石城 / 雾中岛**（ch511-577）：外星海流亡期。黑石城由多家元婴背景势力共管，城内斗法者灭族。
9. **阴冥之地**（ch579-595）：并非乱星海，是经鬼雾进入的异空间，方圆约百里，充斥**绝灵之气**（封死法力与神识）；人类聚居于七八座高墙村落，靠阴冥兽晶与檀云石符御阴兽；唯一出口是东北角的**暴风山**山巅空间裂缝。

## 八、硬约束结论

### ① 乱星海篇结束的标志事件与章号
**标志事件：ch595「脱离」——韩立展开风雷翅、施雷遁术，携紫灵与梅凝自阴冥之地暴风山巅的空间裂缝冲出鬼雾，落点是天南北面的无边海。**

- 章号：**ch595**（离海动作完成）／**ch596**（确认身在无边海、抵达天南溪国闵州，正式进入新篇）。
- 原著卷次分界与此完全吻合：**ch595 是卷4「风起海外」最后一章，ch596 是卷5「名震一方」第一章**。
- 性质：**被迫且意外**。韩立当时的计划只是借妙音门传送阵回内星海；鬼雾吞噬、阴冥之地、出口裂缝三件事全部不在其控制内。他本人在 ch596 也明确表示没想到会这么快回天南。
- **不存在「虚天殿之后启动传送阵回天南」这一情节**。虚天殿在 ch499 就结束了，其后还有 96 章。

### ② 该时点韩立的境界与年龄
- **境界：结丹后期顶峰**（ch596 自述已接近后期顶峰，准备为凝结元婴做准备；ch597 进一步谈及需先至大圆满）。境界演进链：结丹初期 ch398 → 结丹中期 ch529 → 结丹后期 ch544 → 后期顶峰 ch596。
- **年龄：原著未给出确数。** 可确证的两个锚点是：
  1. ch596 韩立自述要了解「天南这**一百多年**的变化」——即离开天南已逾百年；
  2. ch639/640 结婴时，其年龄被明写为「**堪堪二百岁**／二百余岁」，而结婴发生在重返天南之后的落云宗阶段。
- **结论**：ch596 时韩立处于「离乡百余年、年近二百」的区间，但**原著没有任何一句给出具体岁数**。本项目若需数值，应标 `numeric_claim: 推算`，或在文案中回避具体岁数，改写「离开天南已逾百年」。
- 附带约束：韩立自天南服过定颜丹（ch243），**乱星海全程外貌维持在二十许岁**，不可用外貌推断年龄，也不可安排「老去」的表现。

## 九、总结与章节切分建议

现方案把乱星海篇压成 3 章（荒岛→天星城→虚天殿→回天南）**不成立**，有三处结构性错误：其一，把内星海写成了外星海，把非地名的「荒岛」当成主地图，而真正的洞府灵田原型是小寰岛；其二，把虚天殿当成终局，但虚天殿在 ch499 就结束，其后还有 96 章（逆星盟内战、偷渡外星海、九级妖修之祸、阴冥之地）才轮到离海；其三，离海方式完全写反——不是主动启用传送阵，而是被鬼雾掳走后从异空间裂缝意外坠回天南。此外「猎妖令」「黄龙」「紫罗极火（本篇）」三项在原著中查无，必须降级为改编或删除。
