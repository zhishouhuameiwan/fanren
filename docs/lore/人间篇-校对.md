## 九、对现方案人间篇 7 章划分的意见

1. **第2章必须拆开**。方案把「得小瓶 → 发现绿液催熟 → 墨大夫夺舍 → 反杀」压在一章，但原著里得瓶（ch10-14）与发现催熟（ch22-26）相隔整整四年，中间还夹着厉飞雨线与墨大夫摊牌（ch28-32）。绿液是整个「掌天瓶经济」核心循环的解锁点，压缩掉这四年成长期会让核心玩法来得太突兀。
2. **夺舍的机制要改写**。韩立不是主动反杀墨大夫：夺舍过程中他的元神异常强大，反吞了墨大夫元神导致对方当场暴毙（ch56-57），余子童才是他事后主动处决的对象（ch58-61）。战斗设计应做成「神识域内的吞噬战」，而不是一场物理格斗。
3. **第4章（墨府）要去掉余子童**。余子童从未离开神手谷。墨府章的真实冲突是冒名登门、五位夫人各怀心思、墨玉珠婚事、毒杀与夺帮（ch100-125），素材远比原设计丰富，且能自然引出暖阳宝玉与体内寒毒这条支线。
4. **第5章的入门路径完全要改**。太南小会只是修仙界启蒙场景，与入黄枫谷无因果关系。真正的因果链是：七玄门之乱杀金光上人得令牌 → 太南小会买金竺笔学制符 → 偶得杂记识破令牌是升仙令 → 持令直入黄枫谷（ch94、137、141、147）。这条链把前后章紧紧扣上，也更符合「前期不起眼的战利品在中期变成通行证」的游戏性。
5. **第6章的筑基与法宝都要挪**。筑基发生在血色试炼结束数年后的地火屋（ch214-216），不在禁地内；青竹蜂云剑人间篇没炼成，噬金虫是卷4的事。禁地章的真实收获是天地灵药、月阳宝珠见闻、与南宫婉的初次交集，以及交药换来的记名弟子身份。
6. **第7章基本是重写**。战争是天罗国魔道六宗入侵越国，打了两轮，七派战败、四派重地失守、六派远遁九国盟。韩立不是带着筑基修为被追杀，而是先被南宫屏吸干真元跌回炼气期三四层，走投无路才启动古传送阵。这一跌落是人间篇的情绪落点，也是卷4「重修 → 结丹」的动力源，删掉会让卷4开头失去动机。
