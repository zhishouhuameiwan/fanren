## 一、天南地理结构

**天南是一个"地区"级概念，不是单一国家，其下并立多个"国"，国下设"州"。**

- 天南是包含多个国家的广大区域，非单一政权（ch265"天南地区的两大势力"、ch271"整个天南地区"、ch358"天南地区的极北之地"）。
- 层级结构：天南地区 → 国（越国/元武国/天罗国/风都国/姜国/车骑国/紫金国等） → 州（越国下辖"十三州"，如岚州、镜州、建州、辛州） → 具体城/镇/谷/山（ch100"岚州是越国十三州中面积第八大的州府"）。
- 越国在天南的位置：东为风都国（正道盟总部），西为天罗国（魔道六宗老巢），北隔建州与元武国接壤，越国与天罗国之间另隔姜国、车骑国两个小国（ch358、ch144、ch253）。
- 天南极北：越过元武国再往北，直至"无边海"，浑浊无边、鱼类凶猛，元婴期修士飞行年余亦无法穿越，是天南地理上的天然北界（ch358、ch596再次确认"无边海在天南地区的北端"）。
- 天南极南：越国以南穿越紫金国等五六国，是由大小九国结成的"九国盟"，与慕兰大草原的慕兰族"法士"长期交战（ch358）。
- 天南语言/族群：越国、元武国等地居民统称"燕族"，与草原游牧的"慕兰族"相对，韩立曾用"天南语"与外域人交流（ch358、ch365）。
- 韩立离开天南后百余年（第五卷"名震一方"），天南政治格局演变为"四大势力"并立：正道（原正道盟一系）、魔道（原魔道六宗一系）、九国盟（吸收了越国七派残余）、天道盟（十余小国组成的新联盟，核心门派含落云宗等，属溪国一带）（ch598）。
- 乱星海与天南的地理关系：乱星海是天南以外独立的广阔海域，原文未给出精确方位角或里程数字；韩立第一次是被"大挪移令+古传送阵"意外送到乱星海西南海域一座孤岛（ch364、ch365："这里就是乱星海的西南角"）；乱星海分为已探明的"内星海"（俗称即"乱星海"）与未探明的"外星海/妖海"（ch389）；韩立返回天南时，途经的正是"无边海"，说明无边海是连接乱星海与天南北境的过渡海域，但原文未明确两地直线距离（ch596）。**结论：原著对"天南—乱星海"间的确切方位/距离没有给出数字，仅能确认二者隔着凶险的无边海，常规往来极难，多为意外漂流或结丹以上高手远航。**
