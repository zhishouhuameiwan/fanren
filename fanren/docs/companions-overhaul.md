## 0. 一页结论

**现在的问题**：游戏是一部「能从头走到尾的互动小说」。主线忠实、系统齐全，但玩家手里没有选择——没有可带的人，图上没有可找的东西，战斗几乎全是剧情必打。

**改版的四件事**（按对「可玩性」的贡献排序）：

1. **伙伴**：韩立 + 最多 3 人同场，地图上跟着走、对白里插话、战斗里各有一套打法；相处出「默契」，解锁合击、专属支线和情缘戏。
2. **探索**：每张图都有可找的东西（宝箱、采集、隐藏路、明雷精英），伙伴各有一手「场地技」能开别人开不了的路；另做几处可反复进的秘境。
3. **战斗**：保留现有「破势与蓄劲」的骨架，扩成四人队 + 后备换人 + 合击 + 师长护法。
4. **画面**：具名角色全部重画成高清像素——立绘、带表情的头像、两倍精度的地图小人；对白框带头像。

**要你拍板的三件事**（第 10 节）：美术走哪条路线；伙伴与原著的关系怎么处理；先拿哪一段做样板。

## 2. 美术：高清像素化

### 2.1 三条路线各出了一版（韩立、南宫婉）

见 `design_hanli.png`、`design_nangong.png`。三条路线用的是同一份文字设定。

| | A1 百炼 qwen-image-3.0 | A2 GPT gpt-image-2.6-sunburst | B 程序逐像素绘制 |
| --- | --- | --- | --- |
| 原稿画风 | 厚涂，像素感是后处理做出来的 | **原稿就是规整的像素颗粒和硬边色块** | 形状 + 色阶算出来的 |
| 立绘 | 细腻，偏插画 | 干净，最像「高清像素风」 | 做不出立绘级的细节 |
| 缩成 48 像素小人 | 五官容易糊，要补点 | **仍然清楚** | 清楚但概括 |
| 以立绘为参考出三视图 | 能出，服饰一致 | 能出，服饰一致，Q 版味道更足 | 改模板即可 |
| 可复现、过门禁 | 不可复现（每次不同） | 不可复现 | **完全可复现，现有门禁能管** |
| 费用 | 按张计费 | 按张计费 | 无 |
| 本轮用量 | 11 张 | 31 张（其中约 9 张作废或重做；另有 1 次断连后重试成功） | — |

**我的推荐：具名角色走 A2，路人走 B，A1 留作备用通道。**

- 具名角色约 30–40 人，是玩家要记住的人，值得用最好看的那条路线。
- 路人、杂兵三百多个，要的是整齐划一和零成本。把现有 `tools/artgen` 的模板从 16×24 升到 32×48，继续由程序生成、继续受 `ARTGEN_IN_SYNC` 门禁管。
- A1 国内直连、速度快，A2 通道不稳或出图不理想时可以顶上。

### 2.2 规格

| 资产 | 尺寸（像素） | 用在哪 |
| --- | --- | --- |
| 立绘 | 高 220–280，宽 80–130 | 入队、羁绊事件、主菜单队伍页 |
| 头像 | 约 70×65，四种表情（平常 / 笑 / 怒 / 伤） | 对白框、战斗行动条 |
| 地图小人 | 高 48，三头身，四方向 × 走路 4 帧 | 地图行走与跟随 |
| 战斗立姿 | 高约 64–80，8 个姿态 | 横版战斗 |

地图小人按 ×2 显示（现在是 16×24 按 ×3），同屏比现在高约三分之一。`mock_ingame.png` 下半条是实际显示大小的对照。

**一个要说在前面的代价**：地图底图现在是 16 像素一格按 ×3 显示，新小人是 ×2，两者像素颗粒大小不一样（3 比 2）。先换人物、地图后换，中间一段时间画面是「混合颗粒」。地图重烘排在第 8 节的 P4。

### 2.3 管线

1. 写文字设定：外貌只取原著写明的（带章号），其余按身份类型化，自拟的识别记号单独标出。
2. 出立绘原稿 → 以立绘为参考出三视图、走路帧、战斗姿态、表情。
3. 脚本还原成真像素图：测出原稿的像素网格周期，一格取一个颜色，抠掉背景（`work-notes/companions-overhaul/gridpx.py`）。
4. **逐张人工过目**后入库。入库的图不再由程序重生成，门禁改成「文件清单与校验和一致」。

### 2.4 美术试产的结论（2026-11-17）

用 GPT 通道试产了韩立和南宫婉（前期）的走路帧与战斗姿态。报告图：`docs/companions-overhaul/trial_walk.png`、`trial_battle.png`，动图在 `trial/`。切帧脚本 `work-notes/companions-overhaul/trial.py`。

**能做到的：**

- 以三视图小人为参考，一次出整张「4 个朝向 × 4 帧」的走路表和「8 个姿态」的战斗表。
- 帧与帧之间是同一个人，服饰稳定。还原成 48 像素、逐行拉齐之后，16 帧走路的高度：韩立 46–48，南宫婉 45–48。
- 以立绘为参考改一处（加面纱）、或者画同一个人几年后的样子，脸认得出是同一个人。

**必须做的后处理（已写成脚本）：**

- 按连通块切帧。按格子切会把伸出去的剑尖、飞出去的法宝切到邻格里。
- 逐行拉齐。原稿里四个朝向画得不一样高，背面常常高一点。
- 按下半身的中线对齐。按外框居中的话，飘带和伸出去的手会带着人左右抖。

**没解决的和要当心的：**

1. **原稿的像素网格每张都不一样，也不是整数**（3.3 到 7 像素一格）。缩到统一高度是重新采样，细碎的花纹会变成噪点。所以**小人要单独做减法**（大色块、不画花纹）再出表——南宫婉第一遍的走路表就因为衣纹太细而作废。
2. 通道不稳定：有时不听背景色（出黑底）；返回的尺寸不是请求的尺寸；有一次一口气返回两张；有一次断连。出图都要带重试，都要人看。
3. 走路是「站、迈、站、迈」四帧，**没接进游戏里看过**，顺不顺目前只能看动图。
4. 头像的四种表情、首领大图后来也试了（`portraits.png`、`bosses.png`），都是一次出成。没试的：首领的动作帧；人多了以后画风能不能统一。
5. **手会画错。** 南宫婉后期版第一张两只手错了位，是用户看出来的，我自己没看出来。之后每张立绘都要放大手部检查；姿势尽量选手不复杂的（垂在身侧、拢在袖中）。
6. 抠图边缘还有少量碎点，正式入库要逐张清。

**结论：这条路走得通，可以按它做样板。** 帧间不一致这个头号未知排除了；剩下的是工作量和逐张过目，不是做不做得出来。退路（把小人拆成部件用程序做动画）暂时用不上。

### 2.4b Seedream 的重测（2026-11-18）

用户装了 Seedream 5.5 的 MCP，要求用它重测角色生成。用同一份文字设定出了南宫婉前期的一整套：立绘 2 张、面纱版、三视图小人、走路表、战斗表，共 6 次，每次调用都一次返回（返回不等于能用，走路表就有坏帧）。对比图：`compare_nangong_seedream.png`（立绘）、`seedream_nangong_set.png`（立绘 / 面纱 / 小人）、`compare_sheets_seedream.png`（走路表与战斗表，Seedream 与 GPT 并排）。

| | Seedream 5.5 | GPT gpt-image-2.6 |
| --- | --- | --- |
| 脸与画风 | 更圆更甜、眼睛大，偏插画。**用户更喜欢这一边** | 身形修长，更像古风立绘 |
| 原稿的像素感 | 颗粒里混着柔和渐变，还原后才是真像素 | 原稿就是硬边色块 |
| 背景 | 直接出透明底，不用抠 | 要抠，偶尔不听背景色 |
| 照着文字画 | 较松：弯月簪画成了普通发簪，面纱画成了头纱；同一提示词两张差得多 | 较紧：发饰都照着画出来了 |
| 以立绘为参考改一处（面纱） | 姿势、发簪、衣摆一处不差 | 同样一处不差 |
| 走路表（16 帧） | 高 47–49；**背面那行有 2 帧长发画没了**，正面有 1 帧发簪没了 | 高 45–48；没有这类问题 |
| 战斗表（8 姿态） | 都对 | 都对 |
| 稳定性 | 6 次全部一次成功 | 有过黑底、断连、一次返回两张 |

各只出了一次，样本很小：走路表的缺发是不是 Seedream 的通病，要再出几次才知道。量帧间一致性的办法也在这一轮补了一条——每行以第一帧为基准比「深色占比」（缺发的两帧差了 33% 和 36%，正常帧多数只差 0–8%；阈值后来分成两档，见下）。第一版拿中位数当基准，一行坏两帧时中位数自己偏了，一帧都没标出来。

用户看过之后拍板：具名角色全部改用 Seedream（第 10 节第 6 条）。

**南宫婉的 Seedream 定稿（同日）**：`design_nangong_final.png`，分件在 `nangong-final/`。做这一套又得出四条：

1. **整张 4×4 的走路表 Seedream 出不稳。** 出了两次都不能用：一次背面缺发，一次同一行里混进了别的朝向。改成**一个朝向出一条**（正面、侧面、背面各 4 帧，朝左用朝右的镜像）之后才对。
2. **模型一画「迈步」就想转身。** 正面、背面那两条第一次出来，迈步的两帧都转成了半侧面。提示词里写死「严格的正面，两肩水平，不许转身；只让身体下沉、露出的脚换一只、袖子微摆」之后才对。
3. **带渐变的原稿要换一种缩法。** Seedream 的原稿带柔和渐变，用「按票数取色」缩到 48 像素，白衣会缩出雪花点、眼睛时有时无。改成：每一格深色（头发、眼睛、描线）占三成以上就取深色，否则只拿浅色求平均（`final_nangong.py` 的 `clean_downscale`）。
4. **坏帧判据分两档。** 与本行首帧的深色占比差 12%–22% 只提示、由人看；超过 22% 才判坏。正常的侧面迈步（袖子摆开）也能差到 17%–18%，而朝向混了的最低只差 16%——这一段好坏都有，单靠这一个数分不开。

**用户看过后的返工（同日）**：原话「后期改为古典美人风，要十分漂亮，一见钟情的那种美」，并勾了后期版和头像表情。已重出：后期版立绘（月冠、珠花步摇、淡青披帛，眉眼更柔、带一点笑意，不妖艳）、前期四张头像（眼睛更有神，受伤那张不再画成灰暗的脸）、新增后期版四张头像。现在的定稿图是第 2 版。

**韩立的 Seedream 定稿（同日）**：`design_hanli_final.png`，分件在 `hanli-final/`。又得出一条：

5. **后出的角色要拿已定稿的角色当画风参考。** 纯靠文字出的韩立偏写实、头身比也不一样，和南宫婉站在一起不搭；提示词里写「只参考图 1 的画风，画另一个完全不同的角色」并把南宫婉的定稿立绘作参考图，再出就是同一种画风了。以后每个新角色都这样出。

南宫婉这一套出图 12 次：立绘修正 1、面纱 1、后期 1、表情 1、小人 1、整张走路表 1（作废）、战斗表 1、分朝向的走路条 5（其中 2 条因转身重出）。加上前面的首测与一致性测试 6 次、返工 4 次（后期版 2、前期表情 1、后期表情 1）、韩立 11 次（立绘 4、表情 1、小人 1、走路条 4——其中背面那条因剑画反重出了 1 次、战斗表 1），Seedream 共 33 次，每次调用都一次返回。

这一批又试出四条：

- **表情表要写死「四张脸的肤色完全相同」**。只写「略微苍白、不要黑眼圈」不够，陈师妹「伤」那张第一次还是画成了灰紫色的脸。
- **配件丢了，坏帧判据测不出来**。陈师妹朝右那条第 4 帧背上的剑没了、面纱版战斗表「胜利」那格头上的月簪没了，深色占比的差都在 12% 以下。配件得靠人看，提示词里把它单拎出来写「每一帧都要有、位置方向完全相同」。
- **正面走路条出不稳时，别反复重出，拿已经定稿的那一条「只改一处」**。面纱版朝下那条重出两次，一次转成半侧面（判据标出 2 帧），一次四帧几乎不动；改成给露脸版定稿的那条「只加面纱」，一次就对，摆动和迈步原样保留。
- **妖兽的像素网格周期测不准**：鳞片纹理会把周期测乱（同一条蛟，黑的测出 5.33、白的 8.0）。设定图要手工给同一个周期；进游戏前还要统一缩到定下的尺寸，并去掉半透明的残影（墨蛟的尾巴、鳄的腹下）。

### 2.5 造型的依据

你提到按 B 站动画版来做。我的做法是：**造型按原著文字自拟，气质和配色方向可以向动画靠，但不照搬动画版的具体服饰、发型和纹样。**原因是这个仓库是公开的，动画版的角色设计是官方美术。本轮两张图都没有在提示词里提动画，也没有用动画截图作参考。如果你要更贴近动画版，这是你的决定，我可以照做，但建议那批图不进公开仓库。

### 2.6 女角色的美术方向（2026-11-17 用户两次要求）

- 第一次（看过南宫婉第一版）：「女角色要做的更漂亮，性感一些，多一些古风美人的感觉」。
- 第二次（看过照此重画的第二版）：「第一版的感觉更好，第二版有点太妖艳了，南宫婉要清纯少女风，后期是古典庄重风，但是要突出角色的漂亮，前期面纱也要做」。

两次合起来，落成这几条：

1. **漂亮是第一位的。** 五官、妆发、衣饰都要讲究，往古风美人上靠。
2. **气质按人物定，不是人人一个样。** 南宫婉前期清纯少女风，后期古典庄重风。其他人各按原著的性情定：有的清丽，有的端庄，有的才是妩媚。
3. **不要妖艳。** 第二版的问题就在这里：露肩、朱唇、眼神都用过了头。性感只在本来就该妩媚的角色身上用，而且要克制。
4. **少女相的造型不往性感上做。** 这一条是我的把握，不是用户原话。
5. 衣饰：襦裙、大袖衫、披帛、宫绦、玉佩，每人一个主色和一件识别物（南宫婉是雪白 + 朱雀环）。

第二版（`docs/companions-overhaul/design_nangong_v2.png`）作废，留作「妖艳」的反面对照。地图小人缩到 48 像素后衣饰细节会碎——华丽的造型要在小人上做减法。

### 3.2 核心矛盾，和三个处理办法

原著里韩立是独行的人。上表里多数人与他并肩只有几章到十几章，南宫婉只有五章。照原著窗口做，伙伴会是「来了就走」。

| 办法 | 做法 | 得 | 失 |
| --- | --- | --- | --- |
| 甲 严守原著窗口 | 只在上表的章号里入队 | 最忠实 | 你要的「一起探险」基本落空 |
| **乙 正史同行 + 外传历练（推荐）** | 主线里伙伴只在原著窗口入队，但把窗口里的戏加厚；另开一层「历练」内容（可重复秘境、伙伴专属支线），**任何已结识的伙伴都能带**，图鉴里明确标「外传」 | 主线不破，伙伴随时能带 | 历练内容是原创，量要另算 |
| 丙 改编主线 | 让伙伴长期跟着走主线 | 最直接 | 大纲的硬约束和已做完的 13 章剧情要大改 |

大纲 4.4 本来就把「可重复秘境」「情缘系统的同伴化处理」列为允许的改编，乙是在已拍板的框里做事。

### 3.3 队伍

- **上场 4 人**：韩立 + 3 位伙伴；其余在后备，战斗中可换人。
- **地图跟随**：伙伴排成一列跟在韩立身后；走到特定地点会插话。
- **师长不占常规位**：李化元、雷万鹤、马师伯做成「护法」——主线特定战斗和历练里可以请一位，每场只出手一次（一记重招或救场）。这样师父师伯能一起探险，又不会让战斗失去难度。
- **境界悬殊的人**（南宫婉是结丹期）：主线里按原著当时的处境给实力，历练里按队伍水平折算。具体数值在施工图里定。

### 3.4 默契（羁绊）

- **怎么涨**：并肩打仗、带着他走到有话说的地方、送东西（丹药、催熟的灵草——接上掌天瓶经济）、做他的专属支线。
- **涨了有什么**：五档。解锁合击、被动加成、专属支线、立绘新表情、结局旁白里的一段话。
- **情缘线**：南宫婉、陈巧倩、董萱儿、紫灵、元瑶、墨彩环、文思月、梅凝、辛如音。比普通伙伴多两到三场独处的戏。原著里韩立对感情很克制，戏的尺度也照这个来：有来有往的话、一起经一件事、临别的一点表示，不写原著没有的定情。
- **董萱儿**：默契的高低决定第 9 章对峙那一场怎么打——默契低是一场硬仗，默契高她会迟疑、可以不打。

## 4. 探索

| 要素 | 做法 | 现在有没有 |
| --- | --- | --- |
| 宝箱与采集点 | 每张图至少 3 处可找的东西；采集点按日历刷新，接上灵草年份与炼丹 | 没有 |
| 隐藏路与机关 | 伙伴场地技打开只有他能开的路；天眼术看破隐藏物（2026-11-17 订正：天眼术现在只在战斗里起作用，地图上的「看破」是要新做的机制，样板不做） | 都没有 |
| 明雷遇敌 | 敌人在图上看得见，绕得开，从背后撞上先手；精英怪守着好东西 | 现在是暗雷，且只有 6 张图 |
| 场地技 | 每位伙伴一手（3.5 的表）；是现有「路径行动」（打探 / 求购 / 切磋）的延伸 | 路径行动有 |
| 可重复秘境 | 4–6 处，自由组队。第一版用固定底图，每次进去敌人、掉落不同（2026-11-17 订正：原写「用现有 `tools/mapgen` 按房间拼图」，调研发现没有这样的生成器，随机地形以后再议） | 没有 |
| 世界地图与传送 | 去过的地方可以直接回去，方便回头找东西和做支线 | 没有 |
| 图鉴 | 灵草、妖兽、人物录；集到一定数给少量修为或灵石 | 没有 |

设计原则：**带不同的人，同一张图能走出不同的东西。** 第一次来打不开的门，是让玩家以后带对的人再回来的理由。

## 5. 战斗

骨架不动：架势、破绽、破势、劲与蓄劲、首领蓄势、十种攻击类别全部保留。

| 新增 | 说明 |
| --- | --- |
| 四人队与换人 | 上场 4 人，后备可在自己回合换上来（换人不耗劲）。调研核过：现有战斗每个我方单位各自下指令、人数没有上限、站位已处理 4 人以上；**但队伍面板只放得下 3 行，第 4 位会被静默丢掉**，要改。换人留到名册超过 3 人的那一章再做 |
| 伙伴专属机制 | 每人一个只有他有的东西（3.5 的表），让「带谁」成为真选择 |
| 合击 | 默契够的两个人：一人破势时另一人追加一击；默契再高解锁一招双人技 |
| 师长护法 | 每场一次，见 3.3 |
| 灵兽 / 器灵 / 傀儡位 | 把现有的傀儡、化身和后面的啼魂兽统一成一个「随从位」，不占人位 |
| 明雷战与精英 | 可选的战斗要有打它的理由：掉落、图鉴、默契 |
| 难度档 | 至少两档；四人队之后旧的数值都要重量，正好一起做 |

**最重的一件事是重新平衡。** 71 份编成都是按「韩立一人或加一个曲魂」调的，加到四人会全部变成碾压。办法：敌方数值按上场人数给系数，再用现有的 `tests/BattleHand.h` 逐场重量一遍。这是工作量，不是技术难点。

顺带收掉一条旧债：敌方 AI「有法力就只放法术」（技术债 G-34）。

## 9. 风险

1. **动作帧的一致性**（2.4）。P0 先验证，有退路。
2. **重新平衡的量**。71 场 + 新增的可选战斗，是 P3 里最耗时的部分。
3. **混合颗粒**。地图重烘之前，人物和地图的像素大小不一致。
4. **原创内容的量**。外传、默契戏、插话都是原著没有的，写得不好会显得不像这本书。每位伙伴先写一张语气卡，照卡写。
5. **公开仓库里的生成图**。进不进库由你定；造型依据见 2.5。
6. **改动面大**。存档、战斗、地图对象、界面都要动，必须在隔离工作树里做，分阶段合回。
7. **原著核对表有遗漏**（3.1）。每位伙伴开工前重新核一遍他的窗口和手段。
