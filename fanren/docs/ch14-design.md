## 0. 这一章要做到什么

1. **他是一只九级妖修手里的工具。** 碧焰酒逼他破境（ch543–544），半年密室，风雷翅合炼时被当成一块灵石抽灵力（ch547）——洞府里能走的地方都能走，但每一步都在风希眼皮底下；他的反击只有一瓶掺了年份灵药的稀释灵液和一场必须一口气打完的仗（ch549–551，战斗 ①）。
2. **风雷翅是他从妖修手里抢来的命。** 滴血认主之后雷遁成了他的腿（ch553）：战斗里它是一门削架势的身法；世界里它是双峰岛地裂上的两条捷径、一次从元婴手下的脱身（ch559）。
3. **他护的是别人的法，打的是别人的仗。** 元瑶为师姐施还魂术，他坐镇谷口（ch566–568）；来的是逆星盟六道极圣的高徒（ch570–571，战斗 ③）。这一仗没有分出胜负——鬼雾先到了（ch576–577）。
4. **阴冥之地里他是凡人。** 法力神识全封（ch577–580）：战斗 ④ 只交给啼魂兽，战斗 ⑤ 他提着一根兽筋牵着的小剑与两名女修、银色巨猿并肩（`hero_absent`）；高墙村落、口粮、兽晶、石碑、梅凝那一口通灵之气，是他在凡人规矩里找出路（ch579–593）。
5. **出去不是他选的。** 暴风山巅裂缝一开，身后吸力往回拽，风雷翅最后一次雷遁冲出黑雾（ch595）——落在一片陌生的海上，南飞三四个月，是天南最北的溪国（ch596）。**乱星海篇·终，离乡一百多年。**

### 3.1 每一处挂点怎么开始（`mode` / `once`）

分法沿用前十三章：**这件事是他做的（interact），还是发生在他身上的（enter）。** 不用 `auto`（`map_spec` 的 auto 没有实现）。
**enter 挂点一律是落点 / spawn 前方横贯通道的触发带**，不压在 spawn 或脚本落点上——teleport / loadMap 之后引擎**不会**触发脚下的 enter，只在走一步时触发。
**NPC 挂点**（n02、n09、n18、n22）不设 once：脚本开头判 done_flag 已置 → 一句 `return`，判前置未置 → 一句 `return`。

## 17. 施工纪律（沿用前十三章，外加本章的十条）

沿用 `docs/ch04-design.md` 第 8 节、`docs/ch05-design.md`–`docs/ch12-design.md` 各第 17 节与 `docs/ch13-design.md` 第 17 节（第 69–78 条）。本章另加：

79. **境界只推一处**：`realm.advance(realm.CORE_LATE)` 只在 `houqi.lua`、看返回值；`realm.cap` / `realm.demote` 0 处；「顶峰」0 个数据字段。

82. **他不知道的不写**：3.0 判据③清单逐条 0 处；元瑶下落、蛟龙追杀「姓厉的」、风希与妙鹤之战尤其。
