# 白衣少女·戴面纱（`baiyi_shaonv`，问名之前）·立绘提示词记录（2026-11-21）

- 工具：`tools/artgen/seedream_run.js`（Seedream 5.5，`--offline-models --optimize false --watermark false`），每次 1 张，参数都是 `--size 1024x1536 --background transparent`，各带 1 张有透明通道的参考图。
- 差分统一拿本套的基准图当参考图，提示词要求「人、衣服、姿势、构图一概不改，只换表情」。
- 成品处理：透明度低于 8 的碎屑清零；左右各 48 像素渐隐（大袖被画布左右边切成了直边）；没有做别的修改。成品是 `normal/smile/angry/hurt.png`，原图在 `raw/`，弃图在 `rejected/`。
- 底线自查：每张都对照 `docs/heroine-art.md` 第 3 节放大看过脸、胸口、手、佩饰。清丽档，从严：同露脸那套，只多一条面纱。

# 返修·第二版（2026-11-21）

主会话复审后的返修要求：取景太近（脸高约 335 像素，别人 180–216）、白衣下摆半透明、眼睛偏大、面纱看得见嘴和鼻子。
第一版的四张成品挪到了 `v1/`；上面第一版的记录保留不动。这一版的成品是目录里的 `normal/smile/angry/hurt.png`。

- 处理：透明度低于 8 的碎屑清零；这一版人物不碰画布左右边，**不做**左右渐隐。
- `smile` 一张做了后期合成，见下表 V2_smile3。
- 量尺（1024×1536 原图）：头顶（含月牙）y=123，人物 x 在 110–933 之间；脸高（发际到下巴）约 200 像素（陈巧倩约 215）；
  下三分之一里 alpha 在 16–240 之间的像素占可见像素 1.3%–1.5%（第一版 W1 原图是 3.7%，加了渐隐的成品更高）。贴到深色底和草地截图上看过，衣服不透底。
- 底线自查：少女外貌，交领到颈、长袖到腕、厚绸围帔裹住肩臂；神情清冷，吃痛是皱眉抿嘴，没有张嘴、含泪、脸红。
