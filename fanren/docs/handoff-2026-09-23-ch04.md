## 3. 开新章的固定流程（前四章打磨出来的）

1. **读大纲那一章的条目**（`H:/Work/Kys/docs/大纲.md`），它是章节内容的唯一权威。
2. **亲自核原著章号**，不要信大纲的模糊区间。
   ```
   PYTHONIOENCODING=utf-8 python H:/Work/Kys/tools/novel/novel.py find "关键词"
   ```
   子命令是 `find` 不是 `search`；`read` 返回的 JSON 里 `text` 是**行数组**要 join。
   这一步在第 2、3、4 章各改变过一次设计，**第 5 章一次改了三处**（见第 7 节）——**最值钱的一步**。
3. **写 `docs/chNN-design.md`**：硬约束表（带章号出处）、主线节点、**每处挂点的
   `mode`/`once`**、地图、角色、验收。
   **那两列不是可选的**：设计文档没写死的取值，测试只能照着被测物写，而那种判据
   只发现得了「它变了」，发现不了「它错了」（第 3 章两种杀装反，四条测试满格敏感却一条没发现）。
4. **查引擎前置**：照第 4 节那张表看还缺什么。缺的先写 `docs/interfaces-p3-chNN.md` 契约。
5. **登记旗标**——`data/flags.json` **由协调者一个人占**，施工方不得碰。
6. **并行施工**：~~引擎 / 地图 / 文案~~ → 第 5 章起改为**引擎 ∥ 内容，之后再上测试路**（理由见第 9 节：门禁先于编译跑，内容必须成块落地）。
   **战场写文件级白名单，不写描述性的一句话。** 每个代理**用自己的构建槽**。
7. **集成 → 停掉所有代理 → 独立校对 → 按裁决整改 → 复验。**

## 4. 一个模块「可用」需要三样齐备

规则层造好了 ≠ 游戏里能用。缺任何一段，模块都是死的：
**规则层 `src/core/rules/` → 加载器 `src/io/` → 游戏层入口 `src/game/`**。

前三次都是等写内容时才撞上。**已盘点出还差的，开新章前先照这张表查：**

| 模块 | 缺什么 | 第 5 章要不要 |
| --- | --- | --- |
| `rules::Encounter`（随机遭遇） | 缺加载器 + 入口。`data/encounters/` 有 3 张表，地图里 0 个遭遇对象 | 嘉元城街市是天然落点，不是硬需求 |
| `data/quests/` | **空目录、无加载器、连规则层都没有** | **第 5 章是「支线网最密的一章」，这是最大的前置** |
| 势力 / 声望 | `GameState` 里没有任何相关字段 | 「多方势力周旋」要么造，要么用旗标顶 |
| 非伤害法术（天眼术一类） | `core::Magic` 只有 power / castRange / needMp，没有效果种类 | 见第 7 节 |
| `rules::Economy` 的拍卖那一半 | 缺数据目录 + 加载器 + 面板 | 否 |
| `rules::Realm::demote` | 零调用方 | 第 9 章 |

**潜入不必造机制。** 第 3 章「偷秘籍」实际做法是 trigger + 一串 talk + 一次二选一，
**没有任何潜行玩法**，靠文案写出风险感（雨夜、门没锁、走水沟、数架子数了两遍）。
第 5 章的「潜入与伪装」照这个路子走，省下的力气留给支线网。

## 5. 名字是有时间的

原著里某个名词**第一次出现的章号**，决定了它在游戏里最早能出现在哪一章。
提前给出去就再也收不回来。已经因此改过五次。

**这条约束现在有闸门了**：`tests/LexiconTests.cpp` 逐章扫 `data/text/chNN*.json`。
加一个词只要填它的首见章号，它自己就知道该在哪几章闭嘴。

| 口诀的名字（长春功） | ch30 | 第 1、2 章一律不提，它只是「那段口诀」 |

## 8. 四条最贵的教训

**判据从被测物推导出来，就只发现得了变化，发现不了错误。**
第 3 章两种杀的触发方式装反了，四条测试对它满格敏感却一条没发现。
**凡设计文档写死的取值，要有一条不经过驱动、直接读数据、判据写死成设计原文的断言。**

**一条通关测试若可以自己挑起点，它就不再是通关测试。**
第 4 章的 `kStartRealm` 是照着「怎么才能让这条测试绿」反推出来的，
文件头当时**诚实地写明了这一点**——而写明一件事不等于那件事可以成立。
**章与章之间的存档必须首尾相接**：手搭起点可以，但每一个与上一章不同的字段
都要有一行注释说明它是怎么变过来的。

**判据也会对自己的取舍敏感（G-11，第 4 章整改时发现）。**
通关测试那只手换一个吃药门槛，就有一张编成翻面，而翻的那张每次都不一样。
**在拿一只手去量平衡之前，先确认它自己是稳的**——否则你调的是内容，动的是它的脾气。

**内容形状不是规格。**
「仓库里每一场战斗都是单波」在第 4 章转红了，而它恰恰因为多波次功能真的做成了才转红。
凡想写「所有的 X 都…」，先问一句：这是契约写死的规则，还是今天碰巧的样子？

## 9. 并行作业的边界

- **战场写文件级白名单**，不写「你的战场是 X、Y、Z」那种描述。第 2 章那么写过，仍然撞车。
- **每路用自己的构建槽**（`build_logged.bat <槽名>`），共享 `build/` 会撞 `LNK1104`。
- **不要把两件都要改同一个文件的事同时派出去**，哪怕改的是不同的行。
  第 4 章整改时两路并行（引擎 / 文案），白名单零重叠，零冲突——**这个做法有效。**
- **不在白名单里的文件，不要单方面去改**：引擎那一路要往 `scripts/common/api.lua`
  加两行糖衣，它把要加的那一段连原文写进契约交给协调者落地。这是对的做法。
- **复审期间停掉所有其他代理。**
- 测试夹具一律用唯一临时目录名。
- **新章的内容必须成块落地，所以按「引擎 / 内容 / 测试」分路，不按「地图 / 脚本 / 文案」分。**`build.bat` 在编译之前先跑三道门禁，而门禁强制地图↔脚本（挂点声明双向）、脚本→文案 key / 旗标 / 战斗 id、每张图从起点可达、目标链这几类交叉引用。把它们拆给不同代理，谁先落地谁就让门禁红、挡住所有人的构建。第 5 章起的做法：引擎路（`src/`、`tests/`、`tools/validate*`）与内容路（地图、脚本、文案、数据，一个代理按批成块落地，每批落地前单跑门禁）并行；等两路都落地后，再由**另一个代理**按施工图写通关与验收测试——判据不由写内容的人自己出。

## 11. 占位美术（2026-09-22 这一批）

**画面上「这是什么」这件事，现在由 `src/game/MapArt.*` 一个模块回答。**
瓦片语义、室内外两套配色、人物形体、设施字形全在那里；`WorldScene` 与
`BattleScene` 只管「画什么、按什么顺序画」。图集到位后整体换成 `drawTexture`，
调用点不动。

### 修的是什么

不是「没有美术所以难看」，是**两份约定分了家**：`tools/mapgen/genmaps*.py` 文件头
写着 gid 1-8 各是什么，而渲染器对着另一套语义、还用 `gid % 8` 兜底。两边各自自洽，
没有任何工具报警。后果（全 18 张图实测）：

| 错位 | 后果 | 格数 |
| --- | --- | --- |
| gid 8 落到 `8 % 8 == 0` 的兜底上 | 篱笆 / 摊架 / 兵器架**实心挡路却画成可走的草地** | 390 |
| gid 4（front 遮挡）画成不透明水蓝 | 走到树下的人被整个盖住 | 1081 |
| gid 3 一律画成水 | 韩家村那块**菜畦**成了一潭蓝汪汪的水 | 595 |
| overlay 按整格不透明画 | 「地上长了点花草」变成「地表整格被换掉」 | 2113 |

**gid 3 的正解是碰撞层**：生成器对水面的写法固定是「水面不画墙，只挡路」
（`genmaps.py` 与 `genmaps_ch02.py` 各一处），于是**挡路的是水、踩得上的是翻土**。
这条同时修掉「看起来能走、其实走不过去」。

### 别让它再分家

`tests/MapArtTests.cpp`（9 条）拿**全部 18 张真地图逐层对账**：每一层只许出现属于
它的那几种语义，约定之外的编号一律 `Unknown`（画成刺眼的洋红十字，不再就近兜底）。
改任何一侧都会在门禁上红。五处变异实测五处全红（把 gid 8 改回 Ground、gid 3 改成
Ground、两种设施共用一个字、翻土与土路同色、树冠改回不透明）。

### 自检口

```powershell
$env:SDL_VIDEODRIVER="dummy"   # 不开窗口
build-<槽名>\fanren.exe --assets . --map ch02_yaopu --screenshot shot.png
build-<槽名>\fanren.exe --assets . --map ch04_yanwuchang --scene battle:b04_yelangbang_laifan --screenshot battle.png
```

`--map` 直接开在指定的图上（给了它就走那张图的出生点，不沿用存档坐标），
`--scene` 往栈上再压一层：`battle:<编成 id>` / `board` / `talk:<文案 key>`。
认不出的 spec 如实报错退出，不会悄悄拍一张世界层。`--screenshot` 与 `--headless`
同用同样**如实报错退出**，不会写一张全黑的 PNG。exe 是 WIN32 子系统，
**stdout 要重定向才看得到**（`Start-Process -RedirectStandardOutput`）。

它们的摆位由 `DialogueScene::logPageRows` / `logPanelArea` 两个纯函数决定，
`tests/ObjectiveTests.cpp` 钉着「页大小不超过区域画得下的行数」；面板本身走的是
与告示板一模一样的三个 ui 调用（`drawPanel` + `panelContentArea` + `ListView::render`），
而告示板是有截图的。**没有截图的那部分就是没有截图**，别当成验过了。

## 12. 目标提示与对白节奏（2026-09-22 这一批）

### 12.1 玩家第一次知道「下一步该干什么」

在这一批之前，世界层的 HUD 只有地图名与存盘提示两样，**目标一个字也没有**。
引导其实写在对白里（`ch01.zhenshang.hint_talk` 那种「三叔支开他去街上打听」），
但说完就没了；`data/quests/` 至今是空目录。

现在的形状是**目标链**，不是任务系统：

| 东西 | 在哪 |
| --- | --- |
| 数据 | `data/objectives/chNN.json`，一章一条链，`steps` 的数组顺序就是推进顺序 |
| 文案 | `data/text/chNN_objectives.json`（**文件名带 chNN 是有意的**：`LexiconTests` 只扫这个形状的文件，目标文案因此一并受禁词闸门管） |
| 选型 | `src/core/rules/Objectives.h`，纯函数，不开窗口可测 |
| 画面 | `WorldScene`：左上角一行目标 + 目标在本图时把那一格框出来并在上面挂箭头 + 出了视野改画屏幕边缘箭头与格数 + 目标在别的图时高亮通往那张图的门 |
| 面板 | `BoardScene`（地图上 `kind=board` 的告示板，此前按下去是「功用尚未开启」） |

**不新造进度**：每一步的 `done_flag` 就是剧情脚本本来就要置的那个完成旗标，
所以「演到哪儿」与「显示到哪儿」是同一个事实，不可能岔开。

**进度判据是「走得最远的那一步」，不是「第一条没做完的」。** 这条要紧：
`saves/` 下的检查点是跳着置旗标的（只有章末与本章前几节点的），按后者算，
读第 4 章检查点站在演武场上，目标行会写着「在家中听三叔把话说完」并指着韩家村。
`tests/ObjectiveTests.cpp` 有一条用例专钉这个观感。

两道新门禁（`tools/validate.py`）：

- **规则 21**：`display_name_key` 必须是由地图 id 推出来的那个（`ch02_yaopu` → `ch02.map.yaopu.name`）。引擎要按 id 推这个 key 才说得出**没载入的那张图**叫什么（`core::mapDisplayNameKey`）。**没有这条规则就不许那么推。**
- **规则 22**：每一步都得指得到（target_map/target_object 真实存在）、也走得完（`done_flag` 有脚本会置）。第二条尤其要紧：没人置的旗标会让目标行永远卡在那一步，而那种错第一次游玩时看起来一切正常。

两条都在 `tools/validate_selftest.py` 的 L 节有负向用例（4 条，实测 4 条全抓住）。

### 12.2 对白：一个字没改，改的是按键

实测：71 个事件脚本共 995 句，**每个事件中位 13 句、最长 39 句**，最长的一段
连续对白 22 句中间没有任何分支。逐字显示原本 45 字/秒。

- 逐字速度 45 → **60 字/秒**；
- **长按 Ctrl 一路快进**：每框停 0.10 秒自动翻页，39 句的一场约四秒走完；
  **有选项时绝不自动选**——替玩家做选择是这套快进唯一不可接受的后果；
- **Tab 回看**：`Application` 多了一份 `dialogueLog_`（说话人 + 正文，上限 60 行），
  与给测试用的 `spokenKeys_` 是两份，理由写在那儿；
- 对话框右上角常驻一行「Tab 回看　长按 Ctrl 快进」——没有这一行，这两个键等于不存在。

**正文一个字没动**，禁词与转写那几道闸门不受影响。
