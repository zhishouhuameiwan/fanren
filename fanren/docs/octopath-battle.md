## 1. 名词

| 词 | 代码 | 意思 |
| --- | --- | --- |
| 攻击类别 | `core::AttackCategory` | 一击打的是哪一类：兵刃 **剑 刀 拳 暗器 毒**，五行 **金 木 水 火 土**，位序即此序 |
| 架势 | `Unit::toughness / maxToughness` | 护盾点。只有敌人有；我方、识海里都是 0（永不破势） |
| 破绽 | `Unit::weaknesses` | 打中就削架势的那几类 |
| 揭开 | `Unit::revealed` | 已知的破绽（界面上从「？」变成字） |

| 劲 | `Unit::bp` | 我方每人 0–5 点 |

## 2. 规则（带数字）

所有常量在 `src/core/battle/Battle.h` 顶上一处；调平衡只动那里。

### 2.1 回合与行动序

- 每回合开始排一次序。排进去的：**在场、站着、而且那一回合开始时不在破势里**的单位。
- 排序键 = 身法 × (1000 + 扰动) ，扰动在 **±100（千分数，即 ±10%）** 之间，由「种子、回合号、
  单位下标、第几次行动」经 splitmix64 混出来——**不耗 `rng_`**。所以下一回合的序此刻就算得出来，
  界面上的预览（`nextRoundOrder()`）与回合开始真用的是同一个函数 `computeOrder`，不会骗人。
- 一回合行动 n 次的单位占 n 位；第 k 位（0 起）的排序键再乘 (n−k)/n（公分母 2520，全程整数），
  于是首领的两次行动散在回合前后两头，玩家夹在中间有机会打断它。
- 全序：**防御给的先手** → 排序键大的先 → 下标小的先 → 第几位。先手只作用在它的第一位。
- 轮到的人已倒下、不在场、或者刚被打到破势：跳过这一位。
- 例：韩立身法 5 对欧阳飞天 4——5 × 0.9 = 4.5 > 4 × 1.1 = 4.4，扰动最坏也翻不过来，韩立必先手
 （`tests/Ch05BattleDataTests.cpp` 钉着这件事，取代了从前「开场相距 3 格」那一条）。

### 2.2 攻击类别与兵刃

- **普攻**：出手的人挑一样自己有的兵刃（`Action::category`；0 = 位序最前的那一样）。
  拿自己没有的兵刃出手是非法动作：「X 手上没有「刀」这样兵刃」。
- **韩立的兵刃**：空手的「拳」永远有；背包里每件带 `weapon` 字段的兵器再加一样
 （`BattleScene::heroWeapons`）。没有装备系统——揣在身上就算。数据里带 `weapon` 的四件：
  腰带软剑（剑）、制式佩刀（刀）、青锋剑（剑）、青竹蜂云剑（剑）。
- **同伴与敌人**：`data/roles` 的 `weapons`，缺省 `["拳"]`。敌人的普攻也带类别，但我方没有破绽，
  打不出什么来。
- **法术**：类别 = 它的五行（element 的每一位各算一类）；**带毒的（poison > 0）再加一个「毒」**。
  无属性又不带毒的法术打不出任何破绽。
- **毒药**（物品 poison > 0）撒出去 = 一击「毒」，本身不带伤害（2.7）。
- 识海（吞噬模式）里一律没有类别。

### 2.3 劲与蓄劲

- 我方每人**开场 1 点**；**从第 2 回合起每回合开始 +1，上限 5**；上一回合蓄过劲的人，这一回合开始**不加**。
  敌方没有劲。
- 出手时蓄 **0–3 点，且不超过现有**；**只有攻击与法术**蓄得了（物品、防御、逃跑不行）。劲在出手时扣。
- 普攻蓄 N 点：**连击 1+N 击**，每一击单独算伤害、单独判破绽。
- 法术蓄 N 点，看它的 `boost`：
  - `hits`（连发）：**1+N 发**，每发单独判；
  - `power`（缺省）：**威力 ×(1+N)** 喂进同一条法术公式，仍是一击。
- 拒绝理由（菜单上的禁用理由与 `apply` 回绝时的话是同一句）：「只有攻击与法术蓄得了劲」
  「一次最多蓄 3 点劲」「X 的劲不够：要蓄 N 点，只有 M 点」。

### 2.4 架势、破绽、破势；防御与伤害

**一击的结算顺序**（`BattleState::strike`）：

1. 按**出手这一刻**的状态算伤害并扣血（见下「伤害」）。
2. 判破绽：这一击的类别 ∩ 目标的破绽 ≠ 0 即命中破绽：
   - **揭开**：目标与**同一边、同 id** 的单位一起揭开（知道的是「恶狼怕什么」，不是「这一条恶狼
     怕什么」；码头打手敌友两用，打在我方那一位身上什么也试不出来）；
   - **架势 −1**（已破势的、这一击已被打倒的不再削）；
   - 归零即**破势**。
3. 打中过的类别记进 `tested`（我方 AI 探破绽用；不跨战斗、不上存档）。

**破势**：`breakRecoverRound = 破势那一回合 + 2`——

- 本回合若还没出手，就不出了（排到它时跳过）；
- **下一整回合**不排进行动序；
- 再下一回合**开始时**恢复，架势回满（日志「X 重整架势（架势 N）」，`Recover` 事件），照常出手；
- 破势期间受到的伤害 **×2**；**把它打到破势的那一击本身不翻倍**，同一手里之后的几击才翻倍
  ——所以「蓄满劲先破势」与「破势之后再蓄满劲」是两种不同的打法；
- 破势打断蓄势（2.6）。

**防御**：摆开守势，受伤 **×0.5**，护到**自己下一次出手的那一刻**（日志「X 收起守势」，`GuardEnd`
事件）；并且**下一回合排在最前**。因为先手，守势通常在下一回合一开头就散了，它真正护住的是
「这一回合在他之后出手的那些人」。要扛一记预告过的重招，得在**重招那一回合、首领出手之前**防御——
前一回合防御换来的先手，正好让他做得到这一点（连防两回合）。

**伤害**（`BattleState::finalDamage`）：

```
基数 = Damage.cpp 的公式（平砍 攻×2−防，法术 威力×2−防×0.5，境界压制，五行相克，下限 1）
最终 = 基数 × (目标破势 ? 2 : 1) × (目标守势 ? 0.5 : 1) × (出手者正在出重招 ? mult : 1)
       四舍五入（std::lround），至少 1
```

沿用公式是有意的：前四章设计文档里所有「几下打死一个」的推算仍然成立，重调的只是节奏。
识海（吞噬模式）里不乘这几样。

**只有这几类要得了他的命**（`Unit::killableBy`，数据字段 `killable_by`，B2 加）：写了它的敌人，别的类别的
一击照算照报，只是最多把他压到 1（日志补一句「却伤不到 X 的要害」）；缺省 0 = 什么都要得了命。毒本来就不致死。
第一个用户是欧阳飞天（只有「金」，即祭剑符）：第 5 章校对 MEDIUM-1 的拍板「剑符是取他首级的唯一办法」落在这里。

### 2.5 已揭开的破绽跨战斗记住

- `GameState::knownWeaknesses`：`role_id → 位掩码`。`learnWeaknesses` 只增不减。
- 开战时敌人的 `revealed = 已知 ∩ 它的破绽`——上一场揭开过的，这一场一开场就是亮的。
- 收场时（`BattleScene::finish`）把每个敌人的 `revealed` 并进去。**输了、逃了也记**：看见了就是看见了。
- **识海、韩立不在场的仗不写**（前者本来就没有破绽；后者一个字节也不往存档写，契约
  `interfaces-p3-ch05.md` 第 2 节）。
- 存档 **v7**：`"knownWeaknesses": {"wild_wolf": ["剑", "拳"]}`，写**类别名**不写位掩码（位序哪天调整，
  名字不会漂）。读档时不是对象、不是数组、有认不出的名字都算坏档，读档失败。v6 → v7 是空迁移：
  **旧档 = 全都不知道**（那会儿还没有破绽这回事）。
- 施工图 2.2 说破绽「也可由路径行动『打探』提前揭开」：挂点就是 `GameState::learnWeaknesses(roleId, mask)`。
  本路没有给它开脚本 API（那是路径行动那一路的事，见第 9 节）。

### 2.6 首领：多次行动与蓄势

- `actions`（缺省 1）：一回合占几位（2.1）。
- `charge = {every, mult, all, text_key}`：
  - 它**自己的第 every、2×every……个出手回合的第一手**用来宣告（`ActionKind::Charge`，不打人）；
    「出手回合」按它真的出过手的回合数（`roundsActed`）数，破势丢掉的回合不算。节奏写在合法性里
    （`checkCharge`）：时机不对的宣告是非法动作，「X 还没到蓄势的时候」；
  - 宣告时发 `ChargeDeclare` 事件，带 `text_key`，界面亮一条预告横幅（2.4 秒）；
  - **它的下一手是重招**：伤害 × mult；`all` 为真时打对面全体（此刻站着的每一个）；
  - 在它出重招之前把它打到破势：**蓄势作废**（`ChargeInterrupt`，日志「……破势！蓄势被打断」）。
- 例（every 3、actions 1）：第 3 个出手回合宣告，第 4 个出手回合出重招。

### 2.7 毒、物品、法术细则

- 毒的结算照旧（契约 `interfaces-p3-ch03.md` 第 2 节）：回合开始时掉血；**不走防御减半**；**不致死**（最低留 1）；
  续毒「回合取长、强度取高」，不叠加。
- 回合开始时每个单位依次：**恢复破势 → 毒发 → 加劲**。
- **毒药撒出去是一击「毒」**：先判破绽（可能削架势、破势），再挂毒；本身不带伤害。
- 带毒的法术：伤害之后下毒；**一发法术只下一次毒**，不按连发数叠。
- 不伤人的法术（power 0 又不带毒：御风决、护身罡）在战斗里点不了，理由「【X】不是伤人的法术」
 （从前挡它的是「castRange 0 够不着任何人」）。
- 物品不能蓄劲，没有使用距离。纯解毒药用在没中毒的人身上照旧拦下（「X 没有中毒，清毒散用不上」）。
- **道具施法**（第 7 章，契约 `interfaces-p3-ch07.md` 第 2 节）：带 `castMagic` 的物品（天雷子、土牢符、火球符、定神符）用一件 = 以那门法术施展一次——伤害、五行、境界压制、破绽、削架势、破势、打断蓄势与施法逐项相同，只差三处：不耗法力、不吃蓄劲（带劲照旧回绝）、事件 `Act` 记 `Item`，日志「韩立 使用 天雷子——……」；目标照那门法术挑（只挑敌人，看破不挑）。**削架势**（`effect: "stagger"`）不伤人、不判破绽，目标架势减 N 点、到 0 即破势（与打中破绽削到 0 同一条路），事件 `Stagger`；没有架势、已经破势的目标拦在前头（「X 没有架势可削」「X 已经破势」），法力与物品都不扣。

### 2.8 逃跑、波次、胜负

- 逃跑只属于我方：成功率 = 60 + (我方平均身法 − 敌方平均身法) × 2，夹在 [15, 90]。**这是整场唯一耗 `rng_` 的地方**。
- 波次：当前这一波全倒，下一波才进场（`WaveIn` 事件、日志「第 N 波杀到：……」）；新进场的**下一回合**才排进行动序。
  **波与波之间不回血、不重置**：劲、毒、架势、守势照旧带着。
- 胜负：敌方全倒且没有后续波 → `Won`（其中有人遁走 → `EnemyFled`）；我方全倒 → `Lost`；逃跑成功 → `Escaped`。

### 2.9 识海（吞噬模式）

`setDevourMode(true)` 把劲、架势、破绽、揭开、蓄势一并清零（结构上没有，就不可能在哪一处漏判），
伤害按体积算（咬一口 = 攻方体积 / 16，至少 1），不乘破势 / 守势 / 重招。其余照契约
`interfaces-p3-ch03.md` 第 3、5.3 节。`b03_shihai_duoshe` 的编成改成两波（第 8 节决策 9）。

## 3. AI（`src/core/battle/BattleAi.cpp`）

纯函数：只读局面、返回一个动作；不改状态，不耗 `rng_`。每个候选动作返回前都过一遍 `isLegal`。

### 3.1 敌方

1. **蓄势**：宣告合法（会蓄势、没在蓄势、这一回合还没出过手、且 (出手回合数 + 1) % every == 0，
   全在 `checkCharge` 里）→ 宣告。
2. **每个目标上最重的一手**：有伤人的法术且法力够 → 按「估计伤害 × 击数」挑一门（同分取 id 小的）；否则普攻。
   ——「有法术就先放法术」是尸毒爪在暗道里放得出来的原因（技术债 C3-1 在横版里的落点）。
3. **挑目标**：一手打得死的里挑气血最低的；都打不死 → 按种子派生的「随机数」加权挑，**权重 = 1 000 000 / 气血**
  （偏向脆的，但不再是战棋时代「永远打最脆的那一个」的定数）。

### 3.2 我方（只给无头 `runToCompletion` 用；玩家自己按菜单）

候选：每个站着的敌人 × 每样兵刃的普攻，加上每门会的、合法的法术（先不蓄劲）。依次：

1. **有破势的敌人**：挑伤害最重的那一手，**劲蓄满**（min(3, 现有)）。
2. **打得中已揭开的破绽**：先挑架势剩得最少的敌人，再挑气血最少的；同一个敌人里普攻先于法术、伤害重的先。
3. **还有没揭开的破绽**：拿**没试过的类别**去探（普攻先于法术，气血低的先探）。
4. 都没有：打气血最低的那个，普攻优先。

平时劲攒满 5 点时蓄 1 点出手（免得下一回合那一点白白溢出）；一个候选也没有就防御。
**不吃药、不逃跑**——吃药是通关测试里「那只手」的事，不在规则层替玩家做这个决定。

## 4. 事件流（`BattleState::events()`）

日志是给人读的一句话，事件是给画面逐条播动画的结构化记录；**同一处代码同时写两份**，不会走散。
`events()` 从开战起只增不减，画面记一个游标、每帧取游标之后的；`lastActionEvents()` 是最近一次
**成功的** `apply()` 产生的那一段。数值字段一律是「这件事发生之后」的值：画面按事件逐条更新自己
显示的那一份，播完最后一条就与规则层一致。

| 事件 | actor / target | 字段 |
| --- | --- | --- |
| `RoundStart` | — | value = 回合号 |
| `Recover` | target | toughness = 回满后的架势，hp |
| `PoisonTick` | target | value = 掉的气血，value2 = 余下回合，hp，toughness |
| `GuardEnd` | actor | 轮到他出手，守势散去 |
| `BoostSpent` | actor | value = 蓄了几点 |
| `Act` | actor → target | value = ActionKind，category，hits，text = 日志那一句的开头 |
| `Hit` | actor → target | value = 伤害，category，weakness（打中破绽），revealed（这一击新揭开的），hit / hits（第几击 / 共几击），hp，toughness |
| `Break` | actor → target | value = 还要失去几个回合（含本回合），hp，toughness |
| `ChargeInterrupt` | actor → target | 蓄势被打断 |
| `Poisoned` | target | value = 回合，value2 = 每回合 |
| `Cured` | actor → target | 毒解了 |
| `Heal` | actor → target | value = 回的气血，value2 = 回的法力，hp |
| `Guard` | actor | 摆开守势 |
| `Fled` | actor → target | 识海里被咬住的那块脱开、遁走 |
| `Fall` | actor → target | 倒地不起 |
| `Escape` | actor | value = 1 成功 / 0 失败 |
| `WaveIn` | — | value = 进场的是第几波（0 起） |
| `ChargeDeclare` | actor | value = 1 打全体 / 0 单体，text = 预告句的文案 key |
| `End` | — | value = BattlePhase |

**顺序**：

- 回合开始：`RoundStart` → 每个单位依次 `Recover`、`PoisonTick` → 第一位行动者身上若挂着守势则 `GuardEnd`。
- 一手攻击 / 法术：`BoostSpent`（蓄了劲才有）→ `Act` → 每一击 `Hit` → `Break` → `ChargeInterrupt` → `Fled` → `Fall`
  （先看见这一刀，再看见他破势、倒下）→ 带毒的法术在每个目标的几击之后 `Poisoned` → 若因此分出胜负 `End`。
- 毒药：`Act` → 一击 `Hit`（伤害 0，判破绽）→ 可能 `Break` → `Poisoned`。
- 推波：最后一个敌人的 `Fall` 之后紧跟 `WaveIn`。

## 8. 决策记录（B1 自己拍板的，施工图没写或写得不够细）

1. **韩立的兵刃**：拳永远有，背包里每件带 `weapon` 的兵器再加一样；没有装备系统，揣着就算。
   与 `scripts/ch05/heishui.lua`「有软剑就抽剑，没有就换一掌」同一个口径。兵器数据加 `weapon` 字段
  （腰带软剑 剑、制式佩刀 刀、青锋剑 剑、青竹蜂云剑 剑）。
2. **格子字段**：从数据里全部删掉（迁移脚本一次清完）；加载器不读；门禁见到就报错。三层各管一段。
3. **护体罡气与眩晕删掉**，防御改成「减半 ＋ 下回合先手」（施工图 2.4）。罡气要一套「凝多少、什么时候散」
   的账，减半只要一个开关；散的时机与罡气相同（轮到自己下一次出手）。
