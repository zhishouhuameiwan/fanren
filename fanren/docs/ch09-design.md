## 0. 这一章要做到什么

1. **他被自己的门派当成了饵。** 老祖在后殿说他们是日后重立门户的「火种」（ch347），出山百余里就被点去断后（ch347），一个月后在白池山的石亭里听人笑谈「壁虎断尾」——黄枫谷先放出去吸引追兵的那一批，正是他那一队（ch357）。这一章的第一层重量是：**他再也不欠黄枫谷什么**。脱队（ch349）不是背叛，是事后才知道的自救。
2. **故人一个个散了。** 齐云霄已经是一块灵位（ch351），辛如音只剩两年（ch352），马师兄与萧翠儿随大队走了（ch347），南宫婉只剩一句托她堂妹带去的问好（ch362）。每一段都短，但每一段都落在一件「他答应了什么 / 没来得及说什么」上（13.1）。
3. **他最后一次以筑基中期的身手出手。** 三场必打全在跌落之前：突围（ch349）、付家二人（ch350）、董萱儿拦路（ch361）。第三场用的是他在星尘阁用两颗定颜丹换来的飞针与徐老炼坏了大半材料才炼成的飞刀——**玩家刚把新家当攥热，下一个节点就全被吸走了**。
4. **跌落是真的。** 树洞里探一次脉，筑基中期 → 炼气三层（ch361）：气血 380 → 60、法力 250 → 0（上限 30）、攻防回到第 3 章终局的尺度、修为清零、境界上限压到三层、青元剑芒点不动了（第 7 节）。**跌落之后本章不再开仗**——他连走回洞窟都要一路草木皆兵（ch363）；玩家的「弱」要从状态页、法术页与那条回程里看出来，不靠一场打不赢的仗（16.1 第 3 条）。
5. **绝境下他做的是清点，不是崩溃。** 醒来之后他很快定下神（ch361：他想起了三转重元功），拒绝了南宫屏那条「双修重修」的路（ch362），数清手里还剩什么，把最后的中阶灵石嵌进古阵（ch363）。本章三处「抉择」都落在真东西上：炸山前田里的药收不收、要不要向一个刚吸了自己修为的结丹修士再讨几块和元玉、古阵先拿低阶灵石试还是直接上中阶（第 7 节）。
6. **全部重量压在结尾。** 他原想先探明古阵另一头是什么再说，洞顶一掀就只剩一条有去无回的路（ch363）。章末停在黄光吞没他与曲魂的那一刻：**不写他要去哪，不写后记**（天道会、李化元战死都是韩立不知道的事，3.0 表三）。
