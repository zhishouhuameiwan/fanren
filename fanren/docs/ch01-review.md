## 二、原创性核验（方法、样本、结论）

### 方法

比对基准是**原著全文**，不是节选。`H:/Work/Kys/novel/《凡人修仙传》（校对版全本+番外）作者：忘语.txt` 用 Python 读 bytes 后以 GB18030 解码（UTF-8 解码在 offset 59 即失败，确认编码），得 7,613,769 字；剥除全部空白与标点后 **6,458,635 字**作为检索基准。

游戏侧取 `data/text/ch01*.json` 全部 **181 条 / 7,734 字**（剥标点后 6,909 字），**全量**而非抽样。

跑了两道检验，第二道比任务要求的口径更严：

1. **子句级子串检索（任务指定口径）**：按中文标点切分，取长度 ≥12 字的子句共 **129 条**（均长 13.9 字，最长 20 字），剥标点后逐条在原著中做子串查找。
2. **滑窗最长公共子串（自加，更严）**：对 181 条文案的每个起始位置取 6 字窗口，命中则贪婪向右延长，求出每条与原著全文的**最长公共连续片段**。这能抓到"半句照抄"和跨标点拼接，是口径 1 抓不到的。

（改稿后已按同样方法重跑一遍，结果与改稿前完全一致。）

### 样本与结果

**口径 1：129 条 ≥12 字子句，原著命中 0 条。**

**口径 2：181 条全量滑窗，与 645 万字原著的最长公共片段是 9 字。**

### 结论

**原创性合格，且合格得很干净。**

- 9 字是汉语通用搭配在散文中的正常噪声水平。「长出了一口气」「摇了摇头」「愣了一下」这类词组在任何一部百万字中文小说里都必然共现，它们是语言的公共部分，不是作者的表达。命中列表里**没有一条**是有信息量的独特措辞、比喻、句式或人物金句。
- **"改几个字的转写"也没有发现。** 我把游戏文案与原著 ch1–ch9 的对应段落逐场景通读比对（开场家境、三叔提亲、青牛镇、炼骨崖攀爬、墨大夫收人、神手谷安顿、授口诀），确认**事件骨架同源、叙述路径不同**。举证最明显的一处：原著的攀爬是"竹林 → 叠积岩 → 三十余丈山崖 + 十几条打结麻绳 + 正午截止 + 师兄贴身护送"，游戏写成"四轮石壁攀爬 + 起手铃/收手铃"，连考核的物理形态都换了，不存在句式对位。另一处：原著写力竭是「连一根手指都动弹不得」，游戏写成 `ch01.climb.exhausted`「手上的力气是一下子没的，不是慢慢没的」——同一个生理事实，两种完全不同的观察角度。
- 反过来说，**该复用的专有名词都复用对了**：七绝门 / 二百年 / 百年前迁山 / 三四千弟子 / 十几个城镇 / 落凤山 / 炼骨崖 / 神手谷 / 春香（酒）楼 / 象甲功 / 七至十二岁 / 七口人行四——逐条回原著核过，全部属实。原创不等于架空，这个分寸拿住了。

**本项给 5 分。这条标准可以按第 1 章的做法推广到后续十四万字。** 建议把口径 2 的滑窗脚本固化进 `tools/`，每章交付前跑一次，门槛设为"最长公共片段 ≤ 12 字，超过 8 字的条目需人工定性"。

## 三、语气一致性

### 韩立：符合

寡言立住了，且是用**结构**立的，不是靠形容词。`ch01.shandao.hanli_reply`「韩立说了名字，说十岁，再多的没说。张铁也不介意，一个人能把话一直说下去」——用对方的话密反衬他的少言，比直接写"他很沉默"有效。`ch01.modaifu.thanks_after`「他没敢问为什么是自己，像是怕一问出口，这件事就变成假的了」是全章最好的一句心理描写，十岁、贫寒、患得患失三样都在里面。

**不说豪言这条守住了，而且守在最容易破功的地方。** 章末 `ch01.koujue.end`「想的不是这功夫日后能练成什么样，想的是谷里管三顿饭，家里少一张嘴」——明确把"立志"的位置让给了"算账"，正是设计文档要的东西。四组选项（`opt_leave/opt_takeall`、`opt_share/opt_keep`、`opt_why/opt_thanks`、`opt_daily/opt_more`）没有一条是漂亮话，`opt_more` 给的理由甚至是「反正夜里也睡不太着」，很准。

唯一的瑕疵在 `data/text/ch01.json`（本章最早写的 4 条，其余文案晚得多）：`ch01.sanshu.opt_no`「怕临场露怯给三叔丢脸，能不能容我再考虑几天，晚些再给答复」——「露怯」「容我」「给答复」是成年人的书面语，不是十岁山村孩子的话，跟 `ch01_main.json` 的语感明显不是一个水位。见 建议-1。

### 墨大夫：符合，而且是全章完成度最高的一项

**我重点看了这条。结论是他没有被写可疑，反而写得比"不可疑"更好——他现在句句在理，而这些理到第 3 章会变成另一层意思。**

- `ch01.modaifu.mo_ask1` 问年纪、村子、家里几口人，`mo_ask2` 问识不识字。**这四问此刻是坐堂大夫挑药童的常规盘问，回头看是筛选。** 文案没有给任何提示性动作——没有"打量"、没有"眼中闪过"、没有"笑意不达眼底"。
- `ch01.modaifu.why_reply`「挑人不看谁爬得高……他要的是坐得住、记得住的孩子」是这一节的胜负手。它给出一个**完全成立的世俗理由**（抓药要坐得住、要记得住），同时字面本身就是第 3 章的真实标准（坐得住 = 能打坐，记得住 = 能记口诀）。一句话两副面孔，当下不露痕迹。这是正确的伏笔写法。
- `ch01.modaifu.mo_stop`「这孩子是门里收的，不是他家里收的。礼该往山门那边行」——**主动推开三叔的谢礼，是减疑而不是增疑的动作**，处理得对。
- 间接出场也守住了：`ch01.zhenmin.yaofan_2` 让卖药的说「谷中有位坐堂的大夫，手上是有真本事的……没听说谁空手回来」，纯好话，来源可信（同行夸同行合情理）。

唯一擦边的是 `ch01.koujue.mo_last`「这几句不必对旁人讲」。**但这条不仅不该改，还必须留**——原著 ch6 明写「墨大夫并严令二人不[得外传]」，保密是原著事实，且文案给了正当理由（「门里各堂各练各的，说出去徒惹人说闲话」）。保留。

### 三叔、张铁、母亲、考官：符合

- 三叔话密、爱拍胸脯：`ch01.shandao.sanshu_qixuan/history/guimo` 连说三段门派掌故，正是"话密"的行为化；`ch01.fangbang.sanshu_face`「他今日跟人拍过胸脯，这会儿脸上挂不住，只能来回搓手」把语气卡里的"爱拍胸脯"变成了**代价**，不是标签。

## 附：作为全作第一印象，这一章做得怎么样

**先说最好的：这一章的文字是真的好，好到我核验原创性时一度怀疑它抄了——结果是零命中。**

最好的地方是**它敢不写什么**。第一章最容易犯的毛病是急着许诺：让主角说一句狠话，让师父露一个高深的笑，让打坐时涌起一股暖流。这一章一样都没干。`ch01.dazuo.nothing`「什么也没有发生。风从谷口吹进来，药圃那边有虫叫」——这是全章最有种的一句。别人的第一章在这里放烟花，它放了一句"什么也没有发生"，然后让墨大夫补一刀「觉出来的多半是自己想出来的，那种孩子反倒难教」，把玩家的期待按回地面。**一个后面要写十四万字修仙的作品，敢在第一章把"什么都没发生"写得这么笃定，说明它知道自己要什么。**

第二好的是**墨大夫**。「他要的是坐得住、记得住的孩子」——这句话现在是抓药的行规，第 3 章回头看是挑选容器的标准。一句话两副面孔，当下不露一丝痕迹。这是真正的伏笔，不是故弄玄虚。全章没有一次"意味深长地看了他一眼"，这份克制在国产同类文本里罕见。

第三好的是**它记得穷**。饼是两块，掰过一角就剩一块半；三叔拍了胸脯，放榜时脸上挂不住只能搓手；章末落在"家里少一张嘴"。物质的重量一直在，没有被冒险叙事冲淡。

**最弱的地方，是它到不了玩家手里。**

这话不是修辞。按当前实现：玩家走进炼骨崖，笔直向上走三十来步就能出图，跳过考核、放榜、收徒；就算他老老实实爬完四轮，`flag.set(..., 0)` 的缺陷也会让游戏在他明明停在半山腰时告诉他榜上有名，再让墨大夫补一句"够到石檐的统共没有几个，这孩子是其中之一"。**这一章写得最好的那场戏——没爬上去的孩子被单独挑中——没有任何一条路径能看到它。** 编剧把本章的情绪支点写出来了，关卡把它埋了。

所以我对这一章的判断是分裂的：**作为文本它是 4.5 分，作为一关它是 2 分。** 第一印象由后者决定——玩家不会读 json，他只会看到一段前后矛盾的放榜，或者干脆走过去什么都没看到。

还有一处更隐蔽的可惜：这一章为"没登顶却被选中"准备了整套前戏——脚夫说「三四百人里留二三十个」、酒客说「别信什么一口气冲到顶的话」、放榜时「脚底下是他自己站出来的一小块干土」。**前戏全齐了，正戏被一个三目运算符吃掉了。** 这比写不好更可惜，因为写不好可以重写，而这个只差两行代码。

**一句话总结：这一章的问题不是不会写，是写完了没验。** 校对期间创作方自己修掉的那处攀爬数值缺陷，恰恰印证了这一点——文档第 3 节那条教训「给玩法定数值后要穷举验一遍每档结果是否真的可达」写得非常对，但它当时只验在文档上，没验在代码上，直到这次校对才落地。**把这条教训从"穷举验一遍"改成"在代码上穷举验一遍，并把判据留给下一个人复跑"，这一章就是 4 分往上的开局。**
