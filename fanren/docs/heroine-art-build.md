## 1. 总则

- 画法与尺度以用户选定的样张为准：`docs/heroine-art/samples/round2/chen_P3.png`（国风二次元，淡墨细线、柔和上色、夏日的浅色调、淡妆；
  衣着轻薄但穿得整齐）。底线照 `docs/heroine-art.md` 第 3 节。
- 立绘是**加**出来的一层：没有立绘的角色（所有男角色、路人）对白照旧画框里的像素小头像，一处不变。
- 存档版本不升（`kSaveVersion = 10`），不加存档字段；第 7 章章末状态不变；第 1–6、8–13 章的测试断言不改。
- 施工基线：分支 `claude/happy-maxwell-8427c8`（第一期地基包集成分支，含两批试玩返修）。各路在自己的工作树里做，不推送、不合 main。
- 不跑门禁（`validate.py`、`validate_selftest.py`、`genmaps.py --check`、`hd_* --check`），除非用户要求。编译 + ctest 照常。

## 2. 资产规格

- 原图：1024×1536，透明底，膝上半身，一人一图。原图不入库，放 `fanren/docs/heroine-art/final/<角色>/`。
- 入库的是打包后的表：`assets/art/busts/<文件>.png`，一行四格，依次 `normal`、`smile`、`angry`、`hurt`（与像素头像表同一组表情名）。
  每格 840×1260（屏幕上画成 420×630，存两倍，窗口放大到两倍时仍然清楚）。某个表情没画就指回 `normal` 那一格。
- 这类图用线性缩放载入（`engine::ScaleMode::Linear`），不是像素图那种最近邻。
- 表：`data/visual/busts.json`，形状照 `data/visual/portraits.json`（角色 id → 列表，每条可带 `min_chapter` / `max_chapter`，取第一条生效的）。
- 打包工具：`tools/artgen/busts.py`，照 `tools/artgen/hd_pack.py` 的规矩——确定性（同样的输入逐字节同样的输出）、带 `--check`、
  产物的 sha256 记进表里。输入是 `docs/heroine-art/final/` 下的原图与一份清单；做的事是裁掉四周空白、按统一的头顶线与底边对齐、缩到 840×1260、拼表。
  **各角色的头顶在格子里的高度要一致**（换人说话时头不跳）；清单里每个角色可以给一个微调值。

## 3. 路 E：引擎

### 3.1 对白里的立绘

- 说话人在 `busts.json` 里有生效的立绘 → 画立绘；这一句框里的像素小头像不画（正文不用让位）。没有 → 一切照旧。
- 摆法：立绘画在对话框**之下**那一层（框压住它的下缘），站在右侧；右边距 60 左右，屏幕上 420×630。
  - 框在底部（常态）：立绘底边落在框顶以下 40，使人像是从框后面探出来的。
  - 框被 `keepHeroInSight` 挪到上面时：立绘底边贴屏幕底边。
  - 不许盖住左上角的目标框与地名；名签、键位牌、「自动」小标、跳过确认框照旧画在它上面。
- 只在她自己说话的那几句显示。换成她说话时 0.15 秒淡入，换成别人说话或旁白时 0.15 秒淡出（淡出期间不挡输入）。
  连续两句都是她：不重新淡入；表情变了直接换格。
- 表情取这一句的 `face`（与小头像同一个参数）；认不出的退回 `normal`。
- 整段跳过时不画；自动播放照常；回看面板（Tab）里不画立绘，照旧是文字。伙伴插话气泡（`bubble`）不带立绘。
- 无头模式不载图、不警告；图缺了、表坏了当作没有立绘，各警告一次（照 `PortraitBook` 的「缺图不崩」）。
- 截图口：`dlg:` 那一组里加一个能指定说话人与表情的入口，拍立绘用。

### 3.2 队伍页的大图

- 主菜单「队伍」页选中的那个人有立绘时，在页内放一幅大图（高 560 左右）；没有立绘的人照旧只有像素小人。
- 版面由施工方排，要求：现有的属性、法术、默契、「赠与」等信息一样不少、不重叠；选中没有立绘的人时版面不塌。交截图。

### 3.3 测试

- 表的读取与按章生效；摆位的纯函数（框在下、框在上两种）；有立绘时小头像不画、没有时照旧；淡入淡出的时间线；跳过时不画；
  缺图、坏表、认不出的表情三种退路；无头模式不读表。
- 现有对白、头像、菜单相关的测试一条不改断言；必须跟着变的逐条列出。

### 3.4 交付

- 先拿 `samples/round2/chen_P3.png` 一张图走通全流程（四个表情格先都指 `normal`），路 P 的图到了再换。
- 截图：陈巧倩说话（框在下、框在上各一张）、同一段里换成韩立说话（她淡出、韩立的小头像照旧）、队伍页选中她、选中一个没有立绘的人。
- 施工记录 `docs/heroine-art-build-e.md`；全量 ctest；试玩启动脚本放 `build-s7\`，文件名以「看立绘」开头。
