# 手测用的存档检查点

这几份存档是 `tools/mksave` 生成的**开发夹具**，不是玩家存档。
重新生成：

```
build-<你的槽>\mksave.exe . saves
```

## 怎么跑

```powershell
cd H:\Work\Kys\fanren
.\build-ch05main\fanren.exe --assets . --load saves\ch04-siege.sav
```

`--assets` 指资产根目录（`data/` `maps/` `scripts/` `assets/` 的上一级）。不给时从工作目录、exe 目录
各往上找同时有 `data/` 与 `maps/` 的那一层，所以**直接双击 `build\fanren.exe` 就进标题画面**（「继续旅程」读 `saves/quick.sav`）。
不给 `--load` 就是从第 1 章新开一局。

**读档失败会如实报错并退出，不会悄悄给你一个新档**——玩家指名要读这一份，
静默退回新开局是最糟的那种「成功」。两条负向都验过：文件不存在、校验和被改坏。

**从头开始**就是不给 `--load`：

```powershell
.\build-ch05main\fanren.exe --assets .
```

按键：方向键或 `WASD` 移动，`Enter` / `Z` / `空格` 确认，`Esc` / `X` 取消，
`Tab` 菜单，`Ctrl` 快进对话，**`F5` 存盘**。这是默认键位：除方向键、`Enter`、`Esc` 这几个固定键以外，
都能在「设置 → 按键设置」里改（见下面「系统设置」）。`Alt+Enter` 切全屏。
按住会连发的只有方向键；确认、取消、菜单、存盘、路径行动按住只算按了一下（2026-09-28 起）。

手柄（Xbox 优先；键位固定、不可改；`docs/gamepad.md`）：十字键 / 左摇杆 移动，`A` 确认，`B` 取消（野外也开主菜单），
`X` 路径行动，`Y` / `≡` 菜单，**`⧉` 存盘**，按住 `RT` / `RB` 快进。插上就能用，可以热插拔；最后一下按的是手柄时，
画面上的按键提示换成手柄键名，按一下键盘就换回来。破势、挨重击时手柄会震一下，「设置 → 手柄震动」可以关。

## 系统设置（`saves/settings.json`）

音量、全屏、画面缩放、垂直同步、画面特效、战斗震屏、文字速度、手柄震动、键位存在 **`saves/settings.json`**，
**与存档分开**：设置属于这台机器，不属于某一局，存档格式一个字节不动。字段与规则见 `docs/settings.md` 第 2 节。

- 不存在就是全默认（= 改造前的行为）；在标题画面或主菜单的「设置」里改了什么、关面板时才写；`Alt+Enter` 切了全屏也写。
- 文件坏了：按全默认跑、打一行警告，**不覆盖那个坏文件**，直到你在面板里改了什么。
- 指另一份：`--settings <文件>`（例：`--settings saves\lite.json` 拍精简特效下的画面）。
- `--headless` 永远不读；`--screenshot` 只在显式给了 `--settings` 时读，**而且只读不写**——截图不受开发机上的偏好左右，
  拍某种设置下的画面就显式指一份。
- 测试一律写临时目录，跑完测试仓库里**不该有** `saves/settings.json`（验收查这一条；手测玩出来的那一份，交付前删掉）。

## 存盘与续玩

`F5`（手柄 `⧉`）把当下这一局写到 `saves/quick.sav`，屏幕左上角会说一句话——
**存成了和没存成都会说**，不会默不作声。下次接着玩：

```powershell
.\build-ch05main\fanren.exe --assets . --load saves\quick.sav
```

两条限制，都是有意的：

- **只在走格子的时候存得了。** 对话、战斗、面板里按 F5 没反应——
  存档里没有场景栈，那时候存下去读回来是另一个局面。真按到了会告诉你存不了。
- **读档只在启动时。** 运行中热读档要换掉整个场景栈，那是另一件事，没做。

## 建议看这几处

1. **从 `ch04-start` 往东走**，一路玩下去。留意面板里的境界在节点 1、2、4 各涨一次；
   钱一律写「碎银」，**全章不该出现「灵石」**（ch131 才有那个词，属第 6 章）。
2. **从 `ch04-siege` 往东走一步**触发开战，在三选一里**分别试三次**：
   守辕门 / 放进来围歼 / 先下药。三条都该打得赢并走到章末——
   第二条从前是「点得到、走进去必死」，这次整改的 HIGH-2 就是它。
   通关测试那只手（吃药门槛六成）的实测：守辕门收场 90/120、用掉 8 瓶，围歼 100/120、9 瓶，
   先下药 100/120、8 瓶（docs/ch04-design.md 3.2）。这份档站在节点 6 之前：开战、山下镇坊门那一仗、
   殿上那一场与之后的三天备战都还在前面，要一节一节走到攻防战。
3. **打赢之后去校场东头那片焦土**（不在任何一条路上，要自己走过去按确认），
   翻出剑符和**一块黑牌子**。那块牌子是第 6 章才兑现的伏笔：
   **它的名字和描述里不该有任何来历或用途的暗示**，物品栏里它就该像一件杂物。
   有一条测试专门钉着这件事。
4. 金光上人身上那层金：**刀砍上去一下只有 1 点**，只能靠火弹术。
   这是硬约束 7「靠的是算计与毒，不是境界压制」在数值上的落点。

## 已知的限制

- 游戏**不能存档**：`io::saveGame` 目前只有 `mksave` 和测试在调，
  游戏内没有存盘入口（`--load` 是这次为手测补的读档入口）。
  所以中途退出就得从检查点重来。
- `ch04-siege` 是**直接摆出来的状态**，不是玩出来的：它以第 3 章的交接存档为底，前五个节点的
  旗标、境界、法术、药是 `mksave` 照通关测试那一趟的实测写进去的（药 23 瓶是本章俸禄全部炼掉的数）。

  重生成交接存档（`tests/ChapterFixture.h` 文件头）之后，也要重跑一次 `mksave`。
